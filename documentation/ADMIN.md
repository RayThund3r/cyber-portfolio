# Admin panel (/admin)

Sign in at `/admin`. The left menu groups everything:

| Group | Page | What it is for |
|---|---|---|
| Work | Overview | What needs you now: new requests, key numbers |
| Work | Requests | Every request: search, filters, bulk actions, CSV, quick replies, job cards |
| Work | Calendar | Month view of booked visits; tap a day for its agenda, tap a visit to open the request |
| Work | Customers | People grouped from their requests: repeat customers, WhatsApp/call, CSV |
| Build | Studio | Complete business websites you design for clients |
| Build | Templates / Customer sites | The builder's starting templates and prices; sites customers are building |
| Build | Portfolio | Your portfolio projects |
| Site | Content, Settings | Reviews, prices, FAQ, business details, announcement bar, maintenance mode, feature switches |
| Pro pages | Pulse, Board, Chat Lab, AI Providers, AI Access, Events, Games, Health, Launch Pad, Security | Traffic, to-do board, assistant testing, free AI keys, seasonal events, games, checks, setup list, login/2FA/spam filter |

Security page: change your password, set up an authenticator app (QR code and recovery codes), and tune the spam filter.
Changing ADMIN_PASSWORD or ADMIN_TOTP_SECRET in Vercel always resets the saved login (lock-out recovery).
